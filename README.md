## 📌 Project Overview

DocuAI is an AI-powered web platform designed to simplify the creation of structured documents using existing DOCX templates.

The platform allows users to upload a Word document template, automatically analyze its structure, identify fields and tables, generate content using AI, preview the generated information, and create a completed DOCX document while maintaining the original template structure and formatting.

DocuAI combines artificial intelligence, document processing, authentication, database management, and cloud deployment into a single web application.

---

## ✨ Features

- 📄 DOCX template upload
- 🔍 Automatic DOCX template analysis
- 🧩 Field and section detection
- 📊 Table field detection
- 🤖 AI-powered content generation
- ✍️ Manual content generation
- 🖼️ Output screenshot upload
- 👀 Document content preview
- 📄 Automated DOCX generation
- 📥 Download generated documents
- 📂 Document management
- ⭐ Favorite documents
- 🔐 Email and password authentication
- 🔑 Google Sign-In
- ☁️ Cloud deployment
- 📱 Responsive user interface
