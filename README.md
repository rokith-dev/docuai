## 📌 Project Overview

DocuAI is an AI-powered web platform designed to simplify the creation of structured documents using existing DOCX templates.

The platform allows users to upload a Word document template, automatically analyze its structure, identify fields and tables, generate content using AI, preview the generated information, and create a completed DOCX document while maintaining the original template structure and formatting.

DocuAI combines artificial intelligence, document processing, authentication, database management, and cloud deployment into a single web application.

🔍 Template Analysis
DocuAI analyzes uploaded Word templates and identifies the structure of the document.
The analysis process can detect:
- Text fields
- Sections
- Headings
- Tables
- Table fields
- Output sections
- Content types
- Field locations
The detected information is then used to correctly map generated content into the original document.
🤖 AI Content Generation
DocuAI uses Gemini AI to generate content according to the user's requirements and the structure detected from the uploaded template.
The AI can generate structured information such as:
- Titles
- Aims
- Descriptions
- Programs
- Source code
- Results
- Explanations
- Table content
- Other document sections
✍️ Manual Content Generation
Users can also manually enter content instead of using AI generation.
The manual workflow allows users to review and edit the detected fields before generating the final DOCX document.
🖼️ Output Screenshot
DocuAI supports uploading an output or result screenshot as part of the document-generation process.
Supported image formats include:
PNG
JPG
JPEG
WEBP

The screenshot can be associated with the output section of the document and inserted into the generated DOCX file.
📄 DOCX Document Generation
After the required content is prepared, DocuAI maps the information into the uploaded Word template.
The original template is used as the base document so that the generated document retains the existing structure and formatting.
The final document is generated as a .docx file and can be downloaded by the user.
👀 Document Preview
Before generating the final document, users can review the generated content through the document preview interface.
This allows users to verify:
- Field content
- Generated text
- Program/code
- Tables
- Document sections
- Output information
📂 Document Management
Generated documents can be managed through the document management interface.
Users can:
- View generated documents
- Download documents
- Manage documents
- Mark documents as favorites
- Access previously generated documents
🔐 Authentication
Authentication is handled using Supabase.
DocuAI supports:
- Email and password authentication
- Google Sign-In
- User sessions
- Protected application pages
- User-specific document access
🗄️ Database
DocuAI uses PostgreSQL through Supabase for storing application data.
The database manages information related to:
- Users
- Projects
- Documents
- Document metadata
- Templates
- Generated documents
- Favorites
Documents are associated with authenticated users using user IDs.

⚙️ Installation
Clone the Repository
git clone https://github.com/rokith-dev/docuai.git
cd docuai

💻 Frontend Setup
cd frontend
npm install
npm run dev

The frontend runs locally at:
http://localhost:3000

🐍 Backend Setup
Open another terminal:
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

The backend runs locally at:
http://127.0.0.1:8000

🔐 Environment Variables
Create the required environment files before running the application.
Frontend
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_publishable_key
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000

Backend
Configure the required backend environment variables for:
Supabase
Gemini AI
Database
Authentication

Do not commit private API keys, passwords, or secret credentials to the repository.
